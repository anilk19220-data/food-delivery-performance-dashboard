📊 Food Delivery Performance Dashboard

📌 Project Overview

This project presents an interactive Power BI dashboard analyzing food delivery performance using real-world data.
It focuses on understanding how factors like traffic, weather, and delays impact delivery time and customer ratings.

---

📁 Dataset

- Contains 1000+ delivery records
- Key features:
  - order_id
  - delivery_time
  - rating
  - traffic_level
  - weather
  - time_of_day
  - vehicle_type
  - customer_type
  - is_delayed

---

🧩 Data Processing Workflow

- Used SQL to query and filter raw delivery data
- Cleaned and transformed data using Python (Pandas)
- Prepared structured dataset for analysis
- Built interactive dashboard in Power BI

---

📊 Dashboard Features

- KPI Cards:
  
  - Total Orders
  - Average Delivery Time
  - Average Rating

- Visualizations:
  
  - Delay vs Rating Analysis
  - Traffic Impact on Delivery Time
  - Weather Impact on Delivery Time
  - Delivery Category Distribution (Donut Chart)
  - Orders by Time of Day

- Interactive Filters:
  
  - Weather
  - Traffic Level
  - Vehicle Type
  - Customer Type

---

🧠 Key Insights

- Delays reduce customer ratings
- Traffic increases delivery time
- Bad weather causes longer deliveries
- Afternoon is peak order time
